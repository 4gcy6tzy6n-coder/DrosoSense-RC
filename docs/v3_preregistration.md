# v3 pre-registration — Controllability-Aware Biological Substrate Selection

**Status: PRE-REGISTERED 2026-09-23, BEFORE ANY v3 MEASUREMENT.** Everything below is
declared before the candidate scores exist. The selection rule, the candidate definitions,
the gate and the stop-loss are fixed here so that no candidate can be chosen, and no
threshold moved, after seeing a result.

**Why it exists.** The v2 construct phase closed as a **reasonable failure**
([`docs/audit_index.md`](audit_index.md)):

```
C1 PASS (amendments 2 and 3)   C2 PASS   C4 PASS (amendment 1)   C3 FAIL
M5   the substrate HAS the cycles: SCC = 100 %, cycle_edges = 100 %, ORN-reach core = 100 %
M5b  widening W_in support 243 -> 592 nodes peaks at D_eff 1.42 and FALLS to 1.35
```

The v2 substrate has the wiring but the **substrate–input pair** does not reach a large
Krylov effective dimension: `D_eff([B, A·B, …, A¹⁶·B]) ≈ Din`. This is an
**eigenmode-accessibility / controllability-geometry** property, not an
input-support-count one — any `B ∈ R^{N×Din}` has `rank(B) ≤ Din`, and Krylov subspaces can
in principle grow far beyond it.

**What is explicitly NOT the next step.**

* **v3-A (raw synapse counts + one global γ) is not the next main route.** M5 measured it as
  `D_eff(K=16) = 5.68` against row-L1's `5.35` — a small linear-side gain. Repeatedly
  replacing the dynamics after a construct gate fails edges toward "swap until it passes",
  which weakens the research narrative even when done cleanly. It is retained as a
  **supplementary diagnostic only**.
* **More input support.** Excluded by M5b.

---

## 1. What v3 selects, and what it must not look at

**Selection is over biologically-defined candidate substrates, scored by pre-computable
structural / linear-dynamical quantities.** The selection procedure may look at:

* cell types and pathway structure (which populations and which real edges define the
  candidate);
* SCC / cycle statistics;
* the Krylov controllability score;
* the spectrum and the eigenmode coverage of `B`;
* graph statistics (size, degree, weights).

**The selection procedure must NOT look at, at any point:**

* any food-freshness label, TVC value, or any dataset outcome;
* macro-F1, MAE, AUROC, or any model score on any dataset;
* the test split (which is not read at all in v3);
* the C3 gate outcome as a selection criterion — C3 is *run after* the substrate is frozen,
  never used to rank candidates.

**The one permitted overlap with v2 semantics** is that the candidates must still be able
to satisfy **C1.4's population minima** (they are typed, olfactory-derived substrates), and
the selected substrate is then run through C1 → C2 → C4 → C3 unchanged.

## 2. The candidate substrates (biologically defined)

Candidates are **cell-type and pathway definitions**, not graph optima. Each is generated by
a declared, deterministic rule from the delivered annotation and adjacency; none is produced
by searching for a good score.

| id | definition (declared before measurement) |
|---|---|
| **S0** | the v2 substrate: ORN-seeded biological expansion over ORN → PN → KC/LH → MBON/DAN, N=1000 — the *baseline candidate*, included so the selection cannot silently "win" by leaving it out |
| **S1** | **olfactory + recurrent higher-order feedback**: S0's populations plus the higher-order neurons that have real edges **back** into PN or KC (a feedback-closed expansion: any higher-order node with a KC/PN in-edge is admitted with its induced edges) |
| **S2** | **MB/KC-centred recurrent substrate**: seed = KC and MBON populations (mushroom-body intrinsic + output), expanded along KC ↔ MBON ↔ DAN real edges, with the ORN/PN input populations attached by their real ORN→PN edges |
| **S3** | **olfactory + DAN/MBON feedback**: S0's populations plus the DAN and MBON neurons that close loops onto KC (dopaminergic feedback) |
| **S4** | **broader olfactory-learning circuit**: the union of S1 ∪ S3 populations, capped at N=1000 by the same declared frontier rule as S0 |

Every candidate keeps S0's construction discipline: **typed populations only**, the declared
layer order, induced real edges retained, deterministic (no RNG beyond the declared seed).

## 3. The selection scores

Three pre-declared scores, computed **on structure and linear dynamics only**:

```
S1 (PRIMARY)  D_eff([B, A·B, A²·B, …, A¹⁶·B])     effective rank of the Krylov expansion
                                                     (participation ratio over singular values)
S2            eigenmode participation of B         p_i = || v_iᵀ B ||_F over A's leading
                                                     eigenmodes; participation ratio and
                                                     mode-energy entropy of {p_i}
S3            spectral diversity / non-normality    spread of |λ_i| (top-k) and the
                                                     non-normality diagnostic ||A Aᵀ − Aᵀ A||_F / ||A||_F²
```

`B` is the candidate's input mapping, built by the same declared rule as v2's typed-aligned
mapping (amendment 2/3: one channel per receiving node, declared per-layer Din allocation,
density within the declared ceiling). `A` is the candidate's matrix under the **declared
preprocessing** (amendment 1/2 semantics: the raw induced synapse-count matrix scaled by one
global factor to the target spectral radius — i.e. the v2 `rho-matched`-equivalent
normalization for scoring purposes only; the selected candidate is then taken through the
full C1–C4 pipeline to fix its final preprocessing).

**S1 is primary.** S2 and S3 are reported for every candidate and are **diagnostics, not
gates** — they explain *why* a candidate scores as it does (a candidate with high S1 but low
S2 diversity is reaching one dominant mode, which predicts a nonlinear collapse).

## 4. The selection gate (a declared stop-loss, not a success criterion)

```
SELECTION GATE:   S1 = D_eff,Krylov  >=  2 · Din          (= 10 at Din = 5)
```

**Why 2·Din and not the C3 gate's 1.5·Din.** The current substrate measures S1 ≈ 5–6 and its
*nonlinear* state rank lands at ≈ 1.1·Din — the linear score overestimates what survives the
tanh. A candidate chosen at S1 = 7.8 would be expected to fall back below 1.5·Din in the
nonlinear stage. The selection gate is therefore set with **deliberate headroom above the
downstream C3 gate**, so that clearing it means the candidate has room to lose.

**The rule.** If **no candidate** reaches `S1 ≥ 2·Din`, the connectome-reservoir main line
**stops** — see §6. The gate is not lowered to admit the best available candidate.

## 5. The procedure, in order

```
1. generate S0 … S4 by their declared biological rules                  (no scoring)
2. compute S1, S2, S3 and the graph statistics for every candidate      (no C3, no food data)
3. select the candidate with the highest S1 among those clearing the gate
      -- ties broken by higher S2 participation ratio, then by smaller N
4. FREEZE the selection (record the rule, the scores, and the choice)
5. re-run the construct pipeline on the frozen substrate:  C1 -> C2 -> C4 -> C3
6. if C3 PASSES  ->  the first formal food experiment is permitted
   if C3 FAILS   ->  stop; the finding is that this substrate family does not
                     support the recurrence the gate requires
```

**Step 3's tie-break and step 4's freeze are load-bearing**: the selection is a *function of
the structural scores*, and it is committed before C1–C4–C3 run, so the later gate cannot
retroactively re-rank the candidates.

## 6. The stop-loss (the part that must not be negotiated)

```
If every reasonable candidate has S1 ≈ Din           ->  STOP the connectome-reservoir line
If the selected substrate still fails C3             ->  STOP the connectome-reservoir line
```

On either stop: **no v4 is opened.** The project changes the paper question rather than
re-designing the substrate again. The v2/M5/M5b/v3 record stands as the answer to
*"can the Drosophila olfactory connectome serve as a recurrent reservoir for e-nose
sensing?"* — and, per the pre-registration's own discipline, **if all criteria pass and R0
is still indistinguishable from R2, that is the answer too**.

**Why a stop-loss and not another design loop.** Two rounds of substrate/input work have
already produced a precise, mechanism-level negative: the pathway is biologically connected,
topologically cyclic, and fairly counterfactual, and it still does not reach a large
controllability dimension. Continuing to reshape it until a gate passes converts the
construct gate from a check into a search. The gate has to be able to end the line.

## 7. What v3 does not claim, in advance

* **Not** that a candidate will be found. The declared possibility is that all five
  candidates sit near `S1 ≈ Din`, in which case §6 fires.
* **Not** that a high S1 guarantees C3. The selection gate buys headroom, not a verdict.
* **Not** that renaming the object (a "fixed connectome-constrained sensory kernel") is a
  route. That remains an **exit route**, not a main line: the project already has two
  unfavourable facts (`H < X` from A2r/A4r, and weak state expansion), and a rename does not
  improve either. It becomes a paper only if something else is found to be favourable —
  very low parameter count, very low latency, sensor-dropout robustness, or an
  interpretable structural advantage.
* **Not** that any food-task measurement is imminent. Step 6 is the first point at which a
  food experiment is permitted, and only on a PASS.
