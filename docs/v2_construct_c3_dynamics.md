# v2 construct phase — C3, the dynamics gate

**Status: MEASURED — AND C3 FAILS.** The construct phase gate does not pass.

The substrate the other criteria forced (C2 expansion at N=1000: mean out-degree 80.4 on the
ORN/PN/KC/etc. induced block) does not produce a reservoir whose dynamics satisfy the
three signed gates. The failure is structural, not algorithmic: it reproduces, on the
v2 substrate, the same v1 audit findings (`A6`: "the state's effective rank tracked the
channel count, not N") that D5 was written to repair.

Artefact: [`results/audit/v2_construct/C3_dynamics.json`](../results/audit/v2_construct/C3_dynamics.json),
generated by [`ops/audit/v2_construct_check.py`](../ops/audit/v2_construct_check.py)
`--only C3` on the GPU box. Implementation: [`drososense/reservoir/dynamics.py`](../drososense/reservoir/dynamics.py)
(drive, R_t / memory / D_eff, gain x leak grid search, signed metric definitions). Tests:
[`tests/test_reservoir_dynamics_c3.py`](../tests/test_reservoir_dynamics_c3.py).

C3.2 (memory drop ≥ 20 %): **never passes**, on any reservoir, at any (gain, leak). The
memory metric M (real) is **at most** M (A := 0) across the whole grid — the recurrent
graph contributes nothing to the autocorrelation that the metric measures, and the
feed-forward path through W_in carries as much or more memory on its own. This is the
v1 finding (audit A3) reproduced: "Driving with A := 0 reproduced the state's memory
bit-identically".

C3.3 (D_eff ≥ 1.5 · Din): **never passes**, on any reservoir, at any (gain, leak). The
state matrix's effective rank tops out at ~1.1 · Din across the grid, with most points
at 0.3 – 0.7. The substrate's recurrent drive is too weak to spread the state space
beyond the input dimensionality — the same v1 audit A6 finding, "the state's effective
rank tracked the channel count, not N".

## 2. What this means

Both **binding** gates — C3.2 (recurrent contribution to memory) and C3.3 (state-space
spread) — are precisely the defects D5 was written to demand the absence of. v1 measured
both, signed both as construction criteria, and built the C3 gate to fail any
construction that recreates them. The v2 construct phase has recreated them, **on
exactly the substrate the other criteria forced**:

- C2.4 needs mean in-subgraph out-degree ≥ 2.0 → trivially passes.
- But C2.3 wants largest weak component ≥ 0.90·N → trivially passes too, because the
  induced block is **so dense** (mean out-degree 80.4) that everything is connected.
- C1.4 wants ORN ≥ 20 → trivially passes (2,267 ORNs available).
- C1.2 wants ORN fraction ≤ 0.10 · Din → trivially passes (0.243 · 0.05 = 24.3 %).

The density that makes the wiring-rich criteria pass is exactly the density that
prevents the dynamics-rich criteria from passing: with mean out-degree 80.4, the
recurrent term `||A·h||` and the input term `||W_in·x||` are on completely different
scales. Tuning `gain` scales both (it multiplies A only) and `leak` controls how much
of the past the state preserves — but neither can make `||A·h||` comparable to
`||W_in·x||` on a substrate this dense without driving the state into saturation.

## 3. Why this stops the phase

Per the project rule, a criterion that fails is **reported, never relaxed**. And
"close" is not a pass. The owner was explicit:

> 如果 C3 在 shared-scale 下 R0/R2 都过 gate, ... 那么我们后面正式实验的可信度会非常高.

The contrapositive also holds: if C3 does not pass, the construction does not support
the gate, and the construct phase cannot advance to formal experiments. **No formal
experiment will run, no R0-vs-R2 comparison will be made, and the phase is closed
with this finding recorded.** This is exactly the design: the gate exists to prevent
the project from claiming a biological effect on a construction that demonstrably
cannot produce one.

## 4. What is NOT proposed

- **Relaxing C3.2 or C3.3** to fit this substrate. The thresholds (memory drop ≥ 0.20,
  D_eff ≥ 1.5 · Din) were signed because they are what v1 measured as the absence of
  recurrent behaviour. Lowering them to accept the failure would be the
  "relaxing one after seeing model performance" move the discipline forbids, and it
  would also remove the only gate that catches the v1-style defect.
- **Re-running C3 with real D2 windows instead of synthetic.** The synthetic windows
  carry an AR(1) = 0.6 signal so M is measurable, and the metric definitions are
  independent of the input. Real windows would shift the numbers but not the
  criterion satisfaction. The diagnosis is about the substrate, not the input.
- **Adding a "type-pair-preserving rewiring" as a substitute for C4 amendment 1.** D6's
  primary counterfactual is wiring-only, signed and closed. Type-pair preservation is
  a separately pre-registered secondary analysis if R0 ever beats R2.
