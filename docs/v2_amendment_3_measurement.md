## 2. The declared verdict

Amendment 3's decision rule, fixed before the data:

> if some support size clears both gates → the C3 failure was input-geometry-driven;
> if the curve plateaus below both gates → input geometry is excluded as sufficient.

**The curve plateaus below both gates. Input geometry is excluded as sufficient.**

The evidence is not just "it did not pass": it is that the trend **reverses**:

* D_eff factor rises 1.104 → 1.408 → 1.423 (peak at 473 support) and then **falls** to 1.354
  at the full union. Adding the last 119 nodes (KC, 106 of them) *reduces* the effective
  rank — the input subspace grows but the directions it adds are not independent of what
  the recurrent expansion already reaches.
* memory drop rises to **+0.0569** at the full union — a real improvement over the ORN-only
  value of −0.0029, and still **0.14 short** of the 0.20 gate.

Both metrics are monotone-ish in support until the union is complete and neither approaches
its threshold. Extrapolating is not warranted: there is nothing left to add under the
declared receiving set, and the last increment moved the wrong way for D_eff.

## 3. What the two audits together establish

```
M5   the substrate HAS the cycles      SCC = 100 %, cycle_edges = 100 %, ORN-reach core = 100 %
     the linear Krylov is bounded      D_eff(k=16) = 5.35 (row-L1) / 5.68 (gamma-only) ~ Din
M5b  more input support does not fix   D_eff plateaus at 1.42, memory drop at 0.057
```

Neither the graph structure nor the input geometry is sufficient to produce the recurrent
dynamics C3 requires. The remaining candidate is the **dynamics itself** — the
`n1_pre_l1` + tanh + leaky integration regime — which is what amendment 3's decision rule
names as the next step (the "v3-A" branch: raw synapse counts + one global γ, no row-L1).

**A caution stated in advance.** M5 measured gamma-only vs row-L1 as *nearly identical in
the linear Krylov* (5.68 vs 5.35 at K=16). The v3-A change therefore has a **small expected
gain on the linear side**; if it is tried, it should be tried for the *nonlinear* regime
(tanh saturation under a differently-scaled matrix), and its result should be read as a
test of that specific mechanism, not as a promising next attempt.
